# Requirements: Todo — Personal Task Manager with Time Tracking

**Defined:** 2026-03-09
**Core Value:** Every minute of work is tracked and visible — tasks drive focus, time logs prove effort.

## v1 Requirements

### Manual Log Entry

- [ ] **LOG-01**: User can open a "Add entry" form from the Reports page
- [x] **LOG-02**: User can select an existing task when creating a manual log entry
- [x] **LOG-03**: User can set a start date and time for the manual log entry
- [x] **LOG-04**: User can optionally set a duration (hh:mm) for the manual entry
- [x] **LOG-05**: Manual log entry is saved with type "stopwatch" and appears in Reports

## v2 Requirements

### Potential future enhancements

- **LOG-06**: User can add manual entry from Timer page
- **LOG-07**: User can create a log entry with a new (ad-hoc) task name

## Out of Scope

| Feature | Reason |
|---------|--------|
| Free-text task name | Only existing tasks — keeps data consistent |
| Manual entry on Timer page | Reports is the natural home for log management |
| Custom type selection | stopwatch is the appropriate default for manual entries |
